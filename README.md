# Buck Judge: public landing site

Public GitHub Pages site for Buck Judge, a social-first mobile web app for whitetail deer hunters.

- Live site: https://lever10ai.github.io/buckjudge-site/
- Private product repo (plan, review, roadmap): Lever10AI/buckjudge
- Theme: A, Blaze and Timber (dark timber ground, one hunter orange accent, #FF6A13)
- Logo: Variant A, Classic scope (buck in crosshairs, longer and bigger tines)

Status: planning stage landing page only. No app, no signup backend, and no domain yet.
Domains buckjudge.com and buckjudge.app were checked available on 2026-11-20 and are not yet registered. Registration needs Robb's confirmation of the exact domain list and total cost before purchase.
